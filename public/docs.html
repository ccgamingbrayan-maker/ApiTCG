¿Por qué esta documentación es óptima para IAs?

Alta Densidad de Tokens

Sin texto de relleno ni párrafos redundantes. Cada sección entrega los tipos, parámetros, formatos de error y ejemplos directamente comprensibles por un contexto de atención de LLM.

Estándar llms.txt Disponible

La ruta raíz /llms.txt expone el contenido en formato texto plano puro para que crawlers de IA (e.g. GPTBot, ClaudeBot, Antigravity) lean la API en una sola petición.

Tipado TypeScript Riguroso

Todos los modelos de respuesta están definidos con interfaces TypeScript explícitas con soporte para valores opcionales (?) y null.

Modelos de Datos & Esquemas

Estructura tipada de las entidades manipuladas por el servidor.

interface Card {
  id: string;              // UUID único interno en Supabase / local
  tcgplayer_id: number;    // ID numérico de producto en TCGPlayer
  name: string;            // Nombre de la carta (ej: "Monkey.D.Luffy")
  set_name: string;        // Nombre del set (ej: "Romance Dawn")
  set_code: string;        // Código del set (ej: "OP01", "ST01", "EB01", "DON")
  card_number: string;     // Identificador oficial (ej: "OP01-025", "DON!!")
  rarity: string;          // Rareza: "L", "SR", "R", "UC", "C", "SEC", "SP", "MANGA", "DON"
  image_url?: string;      // URL de la imagen local o CDN público
  tcgplayer_url: string;   // Enlace directo en TCGPlayer
  created_at: string;      // ISO 8601 timestamp
  updated_at: string;      // ISO 8601 timestamp
}
interface PriceSummary {
  card: Card;
  latest_prices: {
    market_price: number | null;     // Precio de mercado actual en USD
    low_price: number | null;        // Precio más bajo disponible en USD
    mid_price: number | null;        // Precio medio disponible en USD
    high_price: number | null;       // Precio más alto en USD
    direct_low_price: number | null; // Precio Direct TCGPlayer en USD
    last_sale_price: number | null;  // Precio de la última venta concretada en USD
    scraped_at: string;              // Fecha/hora de última actualización
  } | null;
  price_analysis: {
    average_7d: number | null;       // Promedio móvil 7 días
    average_30d: number | null;      // Promedio móvil 30 días
    average_90d: number | null;      // Promedio móvil 90 días
    lowest_7d: number | null;
    highest_7d: number | null;
    trend: 'up' | 'down' | 'stable' | 'unknown'; // Tendencia calculada
    trend_percentage: number | null; // Variación porcentual
    suggested_price: number | null;  // Precio justo recomendado
    confidence: 'high' | 'medium' | 'low';
  };
  recent_sales: Array<{
    sale_price: number;
    sale_date: string;
    condition: string;
    scraped_at: string;
  }>;
  price_history: Array<PriceSnapshot>;
}
interface InventoryItem {
  id: string;                      // Identificador del registro en inventario
  card_id: string;                 // UUID de la carta asociada en DB
  card_number: string;             // Ej: "OP01-025"
  card_name: string;               // Ej: "Roronoa Zoro"
  set_code: string;                // Ej: "OP01"
  rarity: string;                  // Ej: "SR"
  image_url: string | null;
  tcgplayer_url: string;
  quantity: number;                // Cantidad de copias en posesión (ej: 4)
  purchase_price: number;          // Precio de compra unitario en USD
  condition: string;               // "Near Mint", "Lightly Played", etc.
  notes: string;                   // Observaciones del coleccionista
  created_at: string;
  updated_at: string;
}
interface DeckAnalysisResult {
  id?: string;                     // ID del mazo guardado
  name?: string;                   // Nombre asignado al mazo
  raw_list: string;                // Texto original pegado
  total_cards_needed: number;      // Total cartas requeridas (habitual 50 + Líder)
  total_cards_owned: number;       // Cantidad de cartas presentes en inventario
  total_cards_missing: number;     // Cantidad de cartas que faltan por comprar
  completion_percent: number;      // 0 a 100% de armado
  unique_cards_count: number;
  unique_complete_count: number;
  unique_missing_count: number;
  leader?: {
    card_number: string;
    name: string;
    image_url: string;
  };
  cards: Array<{
    card_number: string;
    name: string;
    rarity: string;
    image_url: string;
    set_code: string;
    needed: number;
    owned: number;
    missing: number;
    is_complete: boolean;
    status: 'complete' | 'partial' | 'missing';
  }>;
  missing_cards_text: string;      // Lista en texto plano para exportar o comprar
}
interface ApiResponse<T> {
  success: boolean;       // true si la operación fue exitosa, false si falló
  data?: T;               // Carga útil de datos devueltos
  error?: string;         // Mensaje descriptivo si success === false
  message?: string;       // Mensaje informativo opcional
}

Cartas, Catálogo & Precios

8 Endpoints
GET /api/cards/sets

Retorna el resumen de todas las expansiones registradas (OP, ST, EB, PRB, DON) con conteo de cartas e imagen de muestra.

// Respuesta Exitosa 200 OK:
{
  "success": true,
  "data": [
    {
      "set_code": "OP01",
      "set_name": "Romance Dawn",
      "count": 121,
      "sample_image": "https://www.optcgapi.com/media/static/Card_Images/OP01-001.jpg"
    }
  ]
}
GET /api/cards/saved

Obtiene la lista de cartas almacenadas localmente, con filtros opcionales de expansión y rareza.

ParámetroTipoObligatorioDescripción
setstringNoCódigo del set (ej. OP01, DON)
raritystringNoRareza (ej. MANGA, SP, SEC, SR, L-AA)
GET /api/cards/search

Búsqueda indexada ultra rápida por nombre o código oficial en la base de datos local.

ParámetroTipoObligatorioDescripción
qstringSí (min 2 car.)Término de búsqueda (ej. OP01-025 o Zoro)
limitnumberNo (default: 500)Límite máximo de resultados
GET /api/cards/tcg-search

Búsqueda en vivo directamente en TCGPlayer mediante scraping (útil si la carta aún no fue agregada a la base de datos).

GET /api/cards/:id

Retorna el resumen completo del precio de mercado, métricas 7d/30d/90d, sugerencia de valor, histórico y últimas ventas.

POST /api/cards/scrape

Raspa una carta en tiempo real desde TCGPlayer, persiste sus precios y retorna el objeto PriceSummary.

// Request Body (JSON) - Al menos uno de estos identificadores es requerido:
{
  "card_number": "OP01-025",
  "card_name": "Roronoa Zoro",
  "url": "https://www.tcgplayer.com/product/453210/...",
  "tcgplayer_id": 453210
}
POST /api/cards/:id/refresh

Vuelve a raspar en TCGPlayer una carta existente en la base de datos para refrescar sus precios y registrar una nueva instantánea.

Reconocimiento & OCR con Inteligencia Artificial

Gemini Vision OCR
POST /api/ai/identify

Analiza una fotografía de una carta física enfocada con la cámara y extrae con alta precisión su código oficial (OP01-025, ST01-001, EB01-006, P-033) o su variante si es una carta DON!! (ej: DON!! Luffy, DON!! Yamato). 

// Request Body (JSON):
{
  "imageBase64": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."
}

// Respuesta Exitosa 200 OK:
{
  "success": true,
  "searchString": "OP01-025",
  "card": {
    "card_number": "OP01-025",
    "name": "Roronoa Zoro",
    "rarity": "SR",
    "set_code": "OP01",
    "image_url": "https://www.optcgapi.com/media/static/Card_Images/OP01-025.jpg"
  }
}

Inventario Personal

5 Endpoints
GET /api/inventory

Obtiene todo el inventario con estadísticas agregadas: total_cards, total_investment y unique_cards.

POST /api/inventory

Registra una carta en el inventario. Si no se conoce el card_id pero se tiene la URL de TCGPlayer en url, el backend la raspa y la indexa automáticamente.

PUT /api/inventory/:id

Actualiza cantidad, condición, precio de compra o notas de un ítem existente.

DELETE /api/inventory/:id

Elimina un registro del inventario.

Analizador & Constructor de Decks

4 Endpoints
POST /api/decks/analyze

Parsea una lista de cartas en texto crudo (formato OPTCGSim, Bandai TCG+ o manual), cruza cada carta contra el inventario y calcula completitud y cartas faltantes.

// Formato soportado en el campo "text":
1xOP01-001
4xOP01-025
4xST01-006
2xOP01-029
GET /api/decks

Obtiene todos los proyectos de decks analizados y guardados en el sistema.

Flujos de Trabajo Recomendados para Agentes de IA

Guía paso a paso para que un agente autónomo ejecute tareas complejas coordinando múltiples endpoints.

Receta 1: Consultar precio de carta por nombre o código (ej. "OP01-025" o "Zoro")
  1. Ejecutar GET /api/cards/search?q=OP01-025.
  2. Si devuelve resultados, tomar el campo id y llamar a GET /api/cards/:id.
  3. Leer data.latest_prices.market_price para el valor actual y data.price_analysis.trend para la tendencia.
  4. Si la búsqueda no retorna nada, ejecutar POST /api/cards/scrape enviando {"card_number": "OP01-025"} para scrapear en vivo desde TCGPlayer.
Receta 2: Escanear carta física y agregar copia a mi inventario
  1. Tomar foto en Base64 y llamar a POST /api/ai/identify con {"imageBase64": "..."}.
  2. Recibir data.searchString (ej: OP05-060).
  3. Buscar la carta con GET /api/cards/search?q=OP05-060 para obtener su card_id.
  4. Registrar en inventario con POST /api/inventory enviando {"card_id": id, "quantity": 1, "condition": "Near Mint"}.
Receta 3: Analizar lista de mazo y obtener lista de compras
  1. Recibir la lista del usuario en texto (tipo OPTCGSim).
  2. Enviar a POST /api/decks/analyze con {"name": "Mi Deck", "text": "..."}.
  3. Informar al usuario su completion_percent y entregarle el campo missing_cards_text con las cartas exactas que necesita conseguir.
